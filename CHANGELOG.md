# Changelog

All notable changes to GrexCode are documented in this file.

The format follows [Semantic Versioning](https://semver.org/): **MAJOR.MINOR.PATCH**.

- **MAJOR** — incompatible API or breaking changes
- **MINOR** — backward-compatible new functionality
- **PATCH** — backward-compatible bug fixes

GrexCode is a fork of [GrexCode](https://github.com/grexlabs/grexcode) v1.17.9.

---

## [Initial GrexCode Release] — Fork from OpenCode v1.17.9

### Added

- Forked from OpenCode v1.17.9 as the foundation for GrexCode
- Grexlabs-specific branding, naming, and repository structure
- Custom models registry integration

### Changed

- Renamed project from OpenCode to GrexCode
- Updated package names from `@openai/opencode` to `@grexlabs/*`
- Rebranded CLI command from `opencode` to `grexcode`
- Updated documentation, metadata, and configuration for Grexlabs

### Removed

- Upstream OpenCode-specific CI, deployment, and infrastructure configurations
